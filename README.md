# Resume Recorder

A tracker that keeps a busy job search in one place.

For every application you can log the company, how excited you are about it, when you applied, the application type, where it stands now, interview notes, a short summary, and links. If you add your own AI API key, an AI agent can analyze a job posting and fill in the details for you, so logging a new application takes seconds instead of a copy-paste marathon.
